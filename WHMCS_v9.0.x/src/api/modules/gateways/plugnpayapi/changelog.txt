v1.0.2 - 2026-08-26
- Filter all inbound fields (control characters, length, type allowlists)
- Mask PAN in log values (Luhn) as well as known keys; never log CVV or passwords
- Restrict cURL to HTTPS, verify TLS, and do not follow redirects
- Unset card data after the gateway request
- Restrict debug log file permissions (0750 / 0640)

v1.0.1 - 2026-08-26
- Do not send WHMCS invoice line items (tax/credit totals can disagree with easycart)
- Format capture amount to two decimal places
- Fall back to WHMCS-{invoiceid} when the gateway omits orderID

- Initial release for WHMCS 9.0.x (target 9.0.7)
- Remote API onsite card capture via pnpremote.cgi
- Authorization Type: authonly or authpostauth
- Merchant gateway overlay: modules/gateways/plugnpayapi.php
- Optional file debug logging with PAN / CVV / password redaction
- PHP 8.2+ / WHMCS gateway API 1.1 / PHP cURL
